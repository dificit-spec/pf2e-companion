# PF2e Компаньон

Офлайн-приложение для Android (8.0+) для игры в Pathfinder 2e (Legacy и Remaster): карточка героя, мастер создания персонажа, кубики, справочник правил, режим Мастера.

## Скачать

Последняя версия — во вкладке [Releases](../../releases/latest), файл `PF2e-Companion.apk`.

Установка: откройте APK на телефоне и разрешите установку из неизвестных источников.
